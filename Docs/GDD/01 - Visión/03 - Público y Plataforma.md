# Público y Plataforma

## Público objetivo

**Edad aproximada:** A partir de 16 años.

**Experiencia esperada:** 
> Casual, intermedia, avanzada.

**Intereses relevantes:** Terror psicológico, salud mental, suspenso.

**Conocimientos previos necesarios:** No se requieren conocimientos previos.

## Plataforma

| Elemento                | Decisión                  |
| ----------------------- | ------------------------- |
| Plataforma principal    | PC con Windows            |
| Plataformas secundarias | Sin plataforma secundaria |
| Método de entrada       | Teclado y ratón           |
| Resolución objetivo     | 1920x1080 (1080p)         |
| Relación de aspecto     | 16:9                      |
| Rendimiento objetivo    | 60 FPS                    |
| Conexión requerida      | No                        |

## Restricciones de plataforma

Documenta limitaciones de hardware, controles, memoria, almacenamiento, distribución o conectividad.

Al ser un juego 2D, no requiere hardware exigente ni conexión a internet. Está diseñado para ejecutarse en computadoras con Windows, incluidas laptops y equipos de gama media y baja, con teclado y ratón.

## Sesión de juego

**Duración esperada de una sesión:** 30 minutos, suficientes para completar el recorrido en una sola sesión.

**Duración total estimada del juego:** 30 minutos, desde el prólogo hasta el desenlace.

## Modelo de distribución

> Gratuito, pago único, educativo, prototipo académico, etc.

Gratuito / prototipo académico.
