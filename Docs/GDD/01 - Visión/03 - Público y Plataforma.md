# Público y Plataforma

## Descripción de la sección

Define para quién se diseña el videojuego y dónde se jugará. Las decisiones de diseño, interfaz, controles y rendimiento dependen de estas variables.

## Público objetivo

**Edad aproximada:** Los usuarios podrán jugar a partir de la edad de 16 años

**Experiencia esperada:**  Casual
> Casual, intermedia, avanzada.

**Intereses relevantes:** Terror psicológico, enfermedades mentales, suspenso.

**Conocimientos previos necesarios:** No se requieren conocimiento previos necesarios.

## Plataforma

| Elemento                | Decisión                  |
| ----------------------- | ------------------------- |
| Plataforma principal    | PC                        |
| Plataformas secundarias | Sin plataforma secundaria |
| Método de entrada       | Teclado y Mouse           |
| Resolución objetivo     | 1920x1080 (1080p)         |
| Relación de aspecto     | 16:9                      |
| Rendimiento objetivo    | 60FPS                     |
| Conexión requerida      | Sí / No                   |

## Restricciones de plataforma

Documenta limitaciones de hardware, controles, memoria, almacenamiento, distribución o conectividad.

Al ser un juego 2D no necesita un equipo de hardware exigente, diseñado para poder jugarse en la mayoría de laptops y equipos de gama baja, el hardware mínimo
## Sesión de juego

**Duración esperada de una sesión:** 15 a 20 minutos.

**Duración total estimada del juego:** La fase demo constará de 20 minutos de videojuego.

## Modelo de distribución

> Gratuito, pago único, educativo, prototipo académico, etc.
