## Cómo abrir el proyecto

1. Instala **Unity 6000.6.3f1** desde Unity Hub, y Git con Git LFS.
2. Clona el repositorio y cambia a `develop` (ver [CONTRIBUTING.md](CONTRIBUTING.md)).
3. En Unity Hub: **Add → Add project from disk** y elige la carpeta `CARENCIA`.
4. La primera apertura tarda unos minutos mientras Unity reconstruye `Library/`.
